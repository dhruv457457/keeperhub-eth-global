# LangChain Paid Workflow Agent

## What it does

A TypeScript LangChain example that discovers KeeperHub capabilities, then
pushes a paid workflow through the x402 / MPP challenge path with explicit
budget controls.

## KeeperHub features used

- `@keeperhub/langchain`
- `KeeperHubToolkit`
- `keeperhub_pay_and_run`
- `keeperhub_list_workflows`
- `kh.payments.catalog(...)`
- payment challenge handling

## How to run

Run the showcase app and open:

`http://localhost:3100/examples/langchain-paid-agent`
